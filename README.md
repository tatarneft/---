# 🖨️ Учёт печати

PWA для учёта сырья и финансов. Работает на iPhone как нативное приложение.

## Установка на iPhone

1. Открой сайт в **Safari**
2. **Поделиться** ⬆️ → **На экран «Домой»**
3. Запусти с иконки → введи код **7939**

## Возможности

- ✅ Полноэкранный режим (без Safari UI)
- ✅ Вход по коду 7939
- ✅ Быстрый ввод «Купил» / «Продал» через шаблоны
- ✅ Шаблоны: Пластик (кг), Клей (г), Магниты (шт), Другое
- ✅ Редактор шаблонов (⚙️ Шаблоны)
- ✅ Учёт сырья на складе по видам
- ✅ Правка фактического склада — недосдача уходит в брак
- ✅ График доходов/расходов за всё время
- ✅ Realtime-синхронизация через Firebase
- ✅ Работает офлайн (кэш + Firebase при восстановлении связи)
